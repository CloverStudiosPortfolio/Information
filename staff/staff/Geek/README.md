### Anti-Cheat / Movement Detection Prototype

A Lua-based anti-cheat and movement monitoring script designed to track character state, detect suspicious movement patterns, and prevent exploit behavior such as teleportation and noclip-like movement.

Key features included:

- Character tracking by player
- Teleportation detection using position and velocity checks
- Noclip detection through raycasting against workspace geometry
- Strike counting and exploit warning logic
- Resetting or correcting an invalid character state when issues are detected
